Metrics Legend

Metric Description
HTML Resources Main HTML page requests, typically the initial page load for each transaction.
Non-HTML Resources Secondary resources loaded by HTML pages, such as JavaScript, CSS, images, fonts, etc.
TTFB
(Time To First Byte)		 Time elapsed between sending the request and receiving the first byte of the response. This measures server processing time and network latency.
TTLB
(Time To Last Byte)		 Total time from request start to receiving the complete response. This includes TTFB plus content download time.
Avg Average (mean) value of all measurements.
Med Median value - the middle point where 50% of measurements are above and 50% below.
p90 90th percentile - 90% of measurements are below this value. Useful for understanding worst-case performance.
