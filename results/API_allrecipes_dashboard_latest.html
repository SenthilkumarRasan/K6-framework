Dashboard Metrics Legend

SLA Thresholds

The metrics in the dashboard are color-coded according to these thresholds:

  • Green: Below 'warn' threshold. Good performance.
  • Yellow: Between 'warn' and 'danger'.
  • Red: Above 'danger' threshold.

Time-Series Charts

  • API Response Time: Tracks response time over the test to spot degradation under load.
  • Transactions Per Second (TPS): Shows the rate of requests, indicating total load on the system.
  • Active Virtual Users: Displays the number of simulated users generating load.

Aggregate & Correlation Charts

  • Response Time Percentiles: Summarizes p90/p95/p99 times to understand user experience.
  • Response Time vs. TPS: Correlates response time and TPS to visualize performance under load.
